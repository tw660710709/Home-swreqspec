# สรุปผลการสัมภาษณ์เจ้าของหอพัก

## 1. กระบวนการโปรโมตและลงข้อมูลหอพักในปัจจุบัน

### 1.1 ปัจจุบันลงประกาศโปรโมตหอพักผ่านช่องทางไหนบ้างเป็นหลัก (เช่น กลุ่ม Facebook, หน้าตึก, โบร์ชัวร์, บอกปากต่อปาก)?

ติดต่อที่หน้าตึก, บอกปากต่อปาก, โทรศัพท์

### 1.2 ข้อมูลอะไรของหอพักที่ต้องคอยอัปเดตบ่อยที่สุด (เช่น ราคา, ห้องว่าง, โปรโมชัน)?

โปรโมชั่น, การบริการ, ค่าเช่าห้อง

### 1.3 เวลาจะลงรูปถ่าย รายละเอียดห้อง หรือสิ่งอำนวยความสะดวก มีปัญหาหรือความยุ่งยากอะไรบ้างไหม?

ไม่ได้โพส

## 2. การจัดการสถานะห้องว่าง

### 2.1 ปัจจุบันบันทึกสถานะห้องว่าง-ห้องเต็มด้วยวิธีไหน (เช่น สมุดจด, Excel, จดในไลน์)?

สมุด, ในคอม

### 2.2 เมื่อมีนักศึกษาติดต่อขอดูห้องพัก มีขั้นตอนนัดหมายอย่างไร และเคยเจอปัญหาเรื่องการนัดซ้อน หรือนัดแล้วไม่มาบ้างไหม?

นัดเวลาและพาไปดูห้องด้วยกัน, ไม่เคย

## 3. การสื่อสารและการคัดกรองผู้เช่า

### 3.1 คำถามที่นักศึกษาหรือผู้ปกครองชอบทักมาถามบ่อยที่สุดจนรู้สึกว่าต้องตอบซ้ำ ๆ คือเรื่องอะไรบ้าง?

ความปลอดภัย, ค่าน้ำค่าไฟ, มีห้องว่างไหม, ราคาเท่าไร

### 3.2 มีวิธีการอย่างไรในการแจ้งเงื่อนไข กฎระเบียบ ค่าน้ำค่าไฟ หรือค่าใช้จ่ายแรกเข้า เพื่อให้มั่นใจว่าผู้เช่าเข้าใจตรงกันตั้งแต่ก่อนย้ายเข้า

บอกตั้งแต่ลูกค้ามาดูห้อง

### 3.3 เมื่อห้องเต็มหรือมีห้องว่างหลุดออกมา มีขั้นตอนการแจ้งเตือนหรือสื่อสารให้คนภายนอกรับทราบอย่างไร

ไม่มีการแจ้งนอกเหนือจากลูกค้ามาถามหน้าหอเอง

## 4. ปัญหาและอุปสรรคต่อการใช้แพลตฟอร์มออนไลน์

### 4.1 ที่ผ่านมาเคยพบปัญหาเรื่องความเข้าใจผิดเกี่ยวกับสภาพห้องพัก สิ่งอำนวยความสะดวก หรือทำเลที่ตั้งบ้างไหม และเกิดจากสาเหตุใด

ไม่เคย

### 4.2 หากมีระบบเว็บไซต์/แอปพลิเคชันรวมหอพัก เคยลองใช้เจ้าไหนมาก่อนไหม และอะไรคือสาเหตุที่เลิกใช้หรือไม่ชอบ?

เคยใช้เว็บนึงเมื่อนานมาแล้วและเลิกใช้แล้ว

### 4.3 ถ้าต้องใช้งานระบบผ่านมือถือ มีความกังวลเรื่องความยากง่ายในการใช้งานตรงจุดไหนเป็นพิเศษหรือไม่?

ไม่มี

## 5. ความต้องการและสิ่งจูงใจในการใช้งานระบบใหม่

### 5.1 หากมีระบบที่เป็นศูนย์กลางสำหรับลงข้อมูลของหอพัก อยากให้ระบบช่วยจัดการหรืออำนวยความสะดวกในเรื่องใดมากที่สุด เพื่อให้ประหยัดเวลาการทำงาน

เรทราคา, แยกหอพักชายหญิง

### 5.2 มีฟังก์ชันหรือรูปแบบการแสดงผลแบบไหนที่คิดว่าจะช่วยดึงดูดและสร้างความน่าเชื่อถือให้กับหอพักของตนเองได้ดีขึ้น (เช่น มีเครื่องหมายยืนยันตัวตน)

ไม่มี

# Feature: แจ้งซ่อมและรายงานปัญหา (Report Repair & Issues)
Spec ID: SPEC-REP-010 | Source: ข้อมูลแจ้งซ่อมจากผู้พักอาศัย | Use case: UC-10  
Owner: ทีมพัฒนาระบบหอพัก | Status: Draft v2 | Updated: 2569-09-20

## Goal
ผู้พักอาศัยสามารถแจ้งปัญหาหรือสิ่งของชำรุดภายในห้องพัก พร้อมแนบรูปภาพประกอบ และสามารถตรวจสอบสถานะการดำเนินงานได้อย่างชัดเจน โดยระบบต้องบันทึกข้อมูลสำเร็จภายใน 2 วินาที (วัดจากเวลา response ของ API) เพื่อให้เจ้าของหอพักรับทราบและดำเนินการแก้ไขได้อย่างรวดเร็ว

## Scope

### In scope
- การเลือกประเภทปัญหาและกรอกรายละเอียดเพิ่มเติม
- การแนบไฟล์รูปภาพประกอบการแจ้งซ่อม
- การตรวจสอบความครบถ้วนของข้อมูลและขนาด/ประเภทไฟล์รูปภาพ
- การบันทึกข้อมูลการแจ้งซ่อมและการแสดงสถานะรายการซ่อมปัจจุบัน

### Out of scope
- การจัดการและอัปเดตสถานะการซ่อมโดยเจ้าของหอพักหรือช่างซ่อม (UC-11 หรือฟีเจอร์จัดการหอพัก)
- การประเมินความพึงพอใจหลังการซ่อมแซม
- การออกใบเสร็จหรือเก็บค่าใช้จ่ายเพิ่มเติมจากการซ่อมแซม

## Constraints
- CON-SYS-01 ผู้ใช้ต้องเข้าสู่ระบบเรียบร้อยแล้ว และมีสิทธิ์เป็นผู้พักอาศัย (Resident) ของห้องพักนั้นๆ จึงจะสามารถใช้งานฟีเจอร์นี้ได้ (Precondition)
- CON-UI-01 แบบฟอร์มต้องรองรับการแสดงผลแบบ Responsive ที่ความกว้างหน้าจอโทรศัพท์ แท็บเล็ต และเดสก์ท็อป

## Requirements
- FR-REP-01 ระบบต้องแสดงแบบฟอร์มให้ผู้ใช้เลือกประเภทปัญหาและกรอกรายละเอียดเพิ่มเติมได้ <- UC-10 main flow ขั้น 2-3, alternative 3a
- FR-REP-02 ระบบต้องรองรับการอัปโหลดไฟล์เพื่อแนบรูปภาพประกอบปัญหา <- UC-10 main flow ขั้น 4, alternative 4a
- FR-REP-03 ระบบต้องมีปุ่มยืนยันการแจ้งซ่อม และปุ่มยกเลิกซึ่งจะพาผู้ใช้กลับสู่หน้าก่อนหน้าโดยไม่บันทึกข้อมูล <- UC-10 main flow ขั้น 5, alternative 5a
- FR-REP-04 ระบบต้องตรวจสอบความถูกต้องและครบถ้วนของข้อมูลแบบ Inline หรือเมื่อกดยืนยัน หากข้อมูลไม่ครบถ้วนให้แจ้งเตือนผู้ใช้กรอกข้อมูลที่จำเป็น <- UC-10 main flow ขั้น 6, exception 6a
- FR-REP-05 ระบบต้องตรวจสอบไฟล์รูปภาพ หากไฟล์ไม่ถูกต้องหรือขนาดเกินกำหนด ระบบต้องแจ้งเตือนและให้เลือกไฟล์ใหม่ <- UC-10 exception 6b
- FR-REP-06 ระบบต้องบันทึกข้อมูลการแจ้งซ่อมลงฐานข้อมูล แจ้งเตือนความสำเร็จ และแสดงสถานะรายการซ่อมให้ผู้ใช้ทราบ <- UC-10 main flow ขั้น 7-8

## Quality Requirements
- NFR-PERF-01 วัดตั้งแต่ผู้ใช้กดยืนยันการแจ้งซ่อม ระบบต้องบันทึกข้อมูลและตอบสนองความสำเร็จด้วยค่า p95 <= 2 วินาทีในสภาวะเครือข่ายปกติ
- NFR-USE-01 แบบฟอร์มแจ้งซ่อมต้องมีป้ายกำกับชัดเจน ใช้งานง่าย และมีข้อความผิดพลาดที่ช่องที่เกี่ยวข้อง
- NFR-SEC-01 ข้อมูลและรูปภาพที่แนบมาต้องรับส่งผ่าน HTTPS และจัดเก็บอย่างปลอดภัยบนเซิร์ฟเวอร์ จำกัดสิทธิ์การเข้าถึงเฉพาะผู้ที่เกี่ยวข้อง

## Acceptance Criteria
- [ ] AC-REP-01 (FR-REP-01, FR-REP-04, FR-REP-06, CON-SYS-01)
      Given ผู้ใช้ที่เป็น Resident เข้าสู่หน้าแจ้งซ่อมและกรอกข้อมูลครบถ้วน
      When  ผู้ใช้กดยืนยันการแจ้งซ่อม
      Then  ระบบบันทึกข้อมูลสำเร็จ แจ้งเตือนผู้ใช้ แสดงสถานะรายการซ่อม และข้อมูลถูกอ้างอิงกับห้องพักของผู้ใช้อย่างถูกต้อง
- [ ] AC-REP-02 (FR-REP-02, FR-REP-05, NFR-SEC-01)
      Given ผู้ใช้กรอกข้อมูลและแนบไฟล์ภาพที่มีขนาด/รูปแบบตามที่กำหนด (.jpg, .png ขนาดไม่เกิน 5MB)
      When  ผู้ใช้กดยืนยันการแจ้งซ่อม
      Then  ระบบอัปโหลดไฟล์ผ่าน HTTPS บันทึกข้อมูลสำเร็จ และเก็บ URL ภาพอย่างปลอดภัย
- [ ] AC-REP-03 (FR-REP-04, NFR-USE-01)
      Given ผู้ใช้เว้นว่างข้อมูลที่จำเป็น (เช่น ไม่เลือกประเภทปัญหา)
      When  ผู้ใช้กดยืนยัน
      Then  ระบบไม่อนุญาตให้บันทึก และแสดงข้อความแจ้งเตือนที่ช่องข้อมูลนั้น
- [ ] AC-REP-04 (FR-REP-05)
      Given ผู้ใช้อัปโหลดรูปภาพผิดประเภท (เช่น .pdf) หรือขนาดเกิน 5MB
      When  ผู้ใช้อัปโหลดไฟล์หรือกดยืนยัน
      Then  ระบบแสดงข้อความแจ้งเตือนให้เลือกไฟล์ใหม่ และไม่อนุญาตให้บันทึก
- [ ] AC-REP-05 (FR-REP-03)
      Given ผู้ใช้กำลังกรอกฟอร์มแจ้งซ่อม
      When  ผู้ใช้กดปุ่ม "ยกเลิก"
      Then  ระบบไม่บันทึกข้อมูล และนำผู้ใช้กลับไปยังหน้าก่อนหน้าทันที
- [ ] AC-REP-06 (NFR-PERF-01)
      Given ข้อมูลในแบบฟอร์มและการอัปโหลดถูกต้อง
      When  ระบบดำเนินการตรวจสอบและบันทึกข้อมูล
      Then  เวลาตอบสนองต้องเสร็จสิ้นภายใน 2 วินาที

## Assumptions & Open Questions
- ASM-01 ผู้ใช้งานต้องมี session/token ที่ระบุว่าพักอยู่ห้องใด ระบบจะดึง `room_id` อัตโนมัติโดยไม่ต้องให้ผู้ใช้พิมพ์เอง
- ASM-02 รูปแบบสถานะเริ่มต้นของการแจ้งซ่อมคือ "รอดำเนินการ" (Pending)
- ASM-03 ประเภทไฟล์ภาพที่รองรับคือ .jpg, .jpeg, .png และมีขนาดไฟล์สูงสุดไม่เกิน 5MB ต่อไฟล์
- ASM-04 รหัส ID `SPEC-REP-010` ถือเป็นรหัสที่ทีมตกลงใช้งานเพื่ออ้างอิงสำหรับฟีเจอร์นี้

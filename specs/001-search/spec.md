# Feature: ค้นหาและดูข้อมูลหอพัก (Dormitory Search & Details)
Spec ID: SPEC-DOR-001 | Source: ข้อกำหนดความต้องการข้อ 1-3, 5-11, 13-18, 20 | Use case: UC-01  
Owner: ทีมพัฒนาระบบหอพัก | Status: Draft v2 | Updated: 2569-09-19

## Goal
ผู้ใช้งานทั่วไป สามารถค้นหา กรอง และเข้าถึงข้อมูลรายละเอียดหอพักได้อย่างสะดวกรวดเร็ว ถูกต้อง และโปร่งใส ภายใน 3 วินาที (วัดจากเวลา response ของ API ค้นหา/ดูรายละเอียดในสภาวะเครือข่ายปกติ) เพื่อประกอบการตัดสินใจเช่าพักอาศัย

## Scope

### In scope
- ค้นหาหอพักด้วยคำค้นหา (ชื่อหอพัก หรือทำเล)
- กรองผลการค้นหาตามประเภทหอพัก (หอพักชาย / หอพักหญิง / หอพักรวม) และช่วงราคาค่าเช่า โดยช่วงราคาจะแสดงเป็นค่า Min - Max ของห้องที่มีราคาแตกต่างกันภายในหอพักเดียวกัน
- แสดงรายการผลลัพธ์การค้นหา พร้อมสถานะห้องว่างและห้องเต็ม
- แสดงหน้ารายละเอียดหอพักเชิงลึกครบถ้วน ได้แก่ ราคาค่าเช่า, รูปภาพห้องพัก, สิ่งอำนวยความสะดวก, ค่าน้ำและค่าไฟ, ค่ามัดจำ, กฎระเบียบ, สถานที่ใกล้เคียง, สัญลักษณ์ยืนยันข้อมูลจริง, ช่องทางติดต่อ และระบบความปลอดภัย

### Out of scope
- การนัดหมายเพื่อดูห้องพักล่วงหน้า (UC-06)
- การจองห้องพัก (UC-12)
- การจัดการและอัปเดตข้อมูลหอพักโดยเจ้าของหอพัก (UC-03, UC-04)
- การตรวจสอบและอนุมัติหอพักโดยผู้ดูแลระบบ (UC-13)

## Constraints
- CON-ACC-01 ผู้ใช้งานทั่วไป (Guest) ต้องสามารถเข้าถึงหน้าค้นหาและดูรายละเอียดได้โดยไม่ต้องผ่านการเข้าสู่ระบบ
- CON-BUS-01 แสดงเฉพาะหอพักที่ผ่านการตรวจสอบและอนุมัติ (Approved) จาก Admin เท่านั้น
- CON-BUS-02 สัญลักษณ์ยืนยันข้อมูลจริง (Verified Badge) จะแสดงเฉพาะเมื่อหอพักมีสถานะ Approved และข้อมูลหอพักได้รับการยืนยันความถูกต้องครบถ้วนตามข้อกำหนดของระบบ
- CON-UI-01 การแสดงผลต้องรองรับ Responsive Web Design ทั้งบนคอมพิวเตอร์และอุปกรณ์พกพา
- DOM-RULE-01 ผู้เช่าต้องได้รับทราบกฎระเบียบ เงื่อนไข และค่าใช้จ่ายทั้งหมดอย่างชัดเจนก่อนการตัดสินใจทำรายการใดๆ (Req #20)

## Requirements
- FR-DOR-01 ระบบต้องค้นหาและแสดงผลรายการหอพักตามคำค้นหา (ชื่อหรือทำเล) และเงื่อนไขตัวกรอง (ประเภทหอพักชาย/หญิง, ช่วงราคา) (Req #1, #2, #15) <- UC-01 main flow ขั้น 3-5
- FR-DOR-02 ระบบต้องแสดงสถานะห้องว่างหรือห้องเต็มของแต่ละหอพักให้ตรงกับฐานข้อมูลล่าสุด (Req #3) <- UC-01 main flow ขั้น 5, 7
- FR-DOR-03 เมื่อคลิกเลือกหอพัก ระบบต้องแสดงหน้ารายละเอียดครบถ้วน ได้แก่ ราคาค่าเช่า, สิ่งอำนวยความสะดวก, ค่าน้ำและค่าไฟ, ค่ามัดจำ, กฎระเบียบ, ข้อมูลความปลอดภัย และช่องทางติดต่อ (Req #1, #2, #5, #7, #8, #9, #10, #14, #16) <- UC-01 main flow ขั้น 7
- FR-DOR-04 ระบบต้องแสดงแกลเลอรีรูปภาพห้องพัก และตำแหน่งสถานที่หรือจุดอำนวยความสะดวกใกล้เคียง โดยข้อมูลสถานที่ใกล้เคียงสามารถแสดงเป็นแผนที่/ปักหมุด หรือรายการระยะทางแบบข้อความตามที่ทีมออกแบบกำหนด (Req #6, #11) <- UC-01 main flow ขั้น 7
- FR-DOR-05 ระบบต้องแสดงสัญลักษณ์ยืนยันข้อมูลจริง (Verified Badge) สำหรับหอพักที่ผ่านการตรวจสอบแล้ว (Req #13) <- UC-01 main flow ขั้น 7
- FR-DOR-06 เมื่อผู้ใช้กดล้างตัวกรอง ระบบต้องรีเซ็ตเงื่อนไขทั้งหมดกลับเป็นค่าเริ่มต้น และโหลดรายการหอพักทั้งหมดขึ้นมาแสดงทันที <- UC-01 alternative 2
- FR-DOR-07 หากค้นหาแล้วไม่พบข้อมูลตามเงื่อนไข ระบบต้องแจ้งเตือนไม่พบข้อมูล และเสนอรายการหอพักใกล้เคียงหรือแนะนำ โดยไม่เกิดหน้าจอว่างเปล่า โดยคำว่า “ใกล้เคียงหรือแนะนำ” หมายถึงหอพักในพื้นที่เดียวกันหรือมีราคาใกล้เคียงตามเงื่อนไขที่กำหนดไว้ (Req #1, #2, #15) <- UC-01 exception 5a
- FR-DOR-08 หากเกิดข้อผิดพลาดในการโหลดข้อมูลรายละเอียดหอพัก ระบบต้องแสดงข้อความแจ้งเตือนความผิดพลาด พร้อมปุ่มให้ลองใหม่อีกครั้ง <- UC-01 exception 7a

## Quality Requirements
- NFR-USE-01 หน้าจอค้นหา ตัวกรอง และการจัดวางข้อมูลในหน้ารายละเอียดต้องใช้งานง่าย ไม่ซับซ้อน (Req #17)
- NFR-ACC-01 ข้อมูล ราคา และรูปภาพของหอพักต้องตรงกับสภาพห้องและเงื่อนไขจริง (Req #18)
- NFR-PERF-01 การค้นหาและแสดงผลรายละเอียดหอพัก: เวลาตอบสนอง p95 <= 3 วินาที ในสภาวะเครือข่ายปกติ
- NFR-SEC-01 ข้อมูลที่รับส่งระหว่างเบราว์เซอร์และระบบต้องเข้ารหัสผ่าน HTTPS (TLS 1.2 ขึ้นไป)

## Acceptance Criteria
- [ ] AC-DOR-01 (FR-DOR-01, FR-DOR-02)
      Given มีหอพักประเภท "หอพักหญิง" ที่มีสถานะ "ห้องว่าง" อยู่ในระบบ
      When  ผู้ใช้เลือกกรองเฉพาะ "หอพักหญิง" และกดค้นหา
      Then  ระบบแสดงเฉพาะรายการหอพักหญิง และแสดงป้ายสถานะ "ห้องว่าง" ตรงตามฐานข้อมูล
- [ ] AC-DOR-02 (FR-DOR-03, FR-DOR-04, FR-DOR-05)
      Given หอพักผ่านการอนุมัติและมีสถานะ Verified
      When  ผู้ใช้คลิกดูรายละเอียดของหอพักดังกล่าว
      Then  ระบบแสดงหน้ารายละเอียดครบทุกส่วน (ราคา, ค่าน้ำไฟ, ค่ามัดจำ, สิ่งอำนวยความสะดวก, กฎระเบียบ, รูปภาพ, สถานที่ใกล้เคียง, ข้อมูลความปลอดภัย, ช่องทางติดต่อ) พร้อมแสดงสัญลักษณ์ Verified Badge ชัดเจน
- [ ] AC-DOR-03 (FR-DOR-07)
      Given ไม่มีหอพักที่ตรงกับเงื่อนไขการค้นหาที่ระบุ
      When  ผู้ใช้กดค้นหา
      Then  ระบบแสดงข้อความ "ไม่พบหอพักตามเงื่อนไขที่คุณระบุ" พร้อมแสดงรายการหอพักแนะนำเป็นทางเลือก
- [ ] AC-DOR-04 (FR-DOR-06)
      Given มีการตั้งค่าตัวกรองการค้นหาค้างไว้
      When  ผู้ใช้กดปุ่ม "ล้างตัวกรอง" (Clear Filter)
      Then  ค่าตัวกรองทั้งหมดถูกรีเซ็ต และระบบโหลดรายการหอพักทั้งหมดกลับมาแสดงผลทันที
- [ ] AC-DOR-05 (FR-DOR-08)
      Given การเชื่อมต่อฐานข้อมูลล้มเหลวระหว่างเปิดดูรายละเอียดหอพัก
      When  ผู้ใช้เข้าหน้ารายละเอียด
      Then  ระบบแสดงข้อความแจ้งเตือน "ไม่สามารถโหลดข้อมูลได้" พร้อมปุ่ม "ลองใหม่" โดยหน้าจอไม่ค้าง
- [ ] AC-DOR-06 (NFR-PERF-01)
      Given มีรายการหอพักในระบบ
      When  ผู้ใช้ทำการค้นหาหรือเปิดหน้ารายละเอียดหอพัก
      Then  เวลาตอบสนอง p95 ต้องเสร็จสิ้นภายใน 3 วินาที

## Assumptions & Open Questions
- ASM-01 ผู้ใช้ทุกคนถือเป็น Guest และมีสิทธิ์อ่านข้อมูลสาธารณะทั้งหมดของหอพักได้เท่าเทียมกัน
- ASM-02 การคำนวณและแสดงผลสถานะห้องว่าง/เต็ม พิจารณาจากสถานะห้องพักล่าสุดที่บันทึกโดย UC-04
- ASM-03 สำหรับหอพักที่มีหลายประเภทห้องในหอพักเดียวกัน ระบบจะแสดงราคาค่าเช่าในหน้ารายการผลการค้นหาเป็นช่วงราคา Min - Max ของห้องที่มีราคาต่างกัน
- ASM-04 สำหรับ “สถานที่ใกล้เคียง” ในหน้ารายละเอียด ระบบจะแสดงเป็นรายการระยะทางแบบข้อความพร้อมชื่อสถานที่ ไม่ใช้แผนที่/ปักหมุดผ่าน Google Maps API เป็นค่าเริ่มต้น
- ASM-05 สำหรับ “รายการหอพักแนะนำ” หลังค้นหาไม่พบผล ระบบจะเลือกแสดงหอพักที่มีทำเลหรือช่วงราคาใกล้เคียงกับเงื่อนไขค้นหามากที่สุด โดยจำกัดสูงสุด 5 รายการ

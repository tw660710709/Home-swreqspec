หมายเหตุ:
- Required fields/documents หมายถึงรายการที่กำหนดเป็น Required ในแบบฟอร์มลงทะเบียนหอพักเท่านั้น; ตารางนี้ไม่สร้างหรือแจกแจงรายการใหม่
- การแก้ไขข้อมูล/เอกสารก่อนส่งตรวจสอบใหม่เป็นความรับผิดชอบของ UC-03; กรณีทดสอบ UC-13 ตรวจเฉพาะการรับส่งตรวจสอบใหม่และการกลับเป็น `Pending Review`
- ไม่กำหนดรูปแบบ UI ของ Notification หรือข้อความแจ้งข้อผิดพลาดที่แน่นอน เพราะ Spec ไม่ได้ระบุไว้
- การพิจารณาความชัดเจนและเข้าใจได้ของเหตุผลเป็นการตรวจโดยผู้ทดสอบ ไม่เพิ่มเกณฑ์ข้อความเฉพาะนอกเหนือจาก Spec

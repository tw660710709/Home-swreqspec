# Feature: เขียนและแก้ไขรีวิวหอพัก (Dormitory Review Management)

Spec ID: SPEC-DOR-009 | Source: ข้อกำหนดความต้องการด้านรีวิวหอพัก | Use case: UC-09

Owner: ทีมพัฒนาระบบหอพัก | Status: Draft v2 | Updated: 2569-09-20

## Goal

ผู้พักอาศัยสามารถให้คะแนน เขียนรีวิว แนบรูปภาพประกอบ และแก้ไขรีวิวของตนเองได้อย่างสะดวก เพื่อแบ่งปันประสบการณ์การพักอาศัยจริงและช่วยให้ผู้สนใจเช่าใช้ข้อมูลรีวิวประกอบการตัดสินใจ

## Scope

### In scope

* แสดงแบบฟอร์มสำหรับเขียนรีวิวหอพัก
* ให้ผู้พักอาศัยให้คะแนนหอพักด้วยระบบดาว
* ให้ผู้พักอาศัยเขียนข้อความแสดงความคิดเห็น
* แนบรูปภาพสภาพห้องพักจริงประกอบรีวิว
* แก้ไขคะแนนและข้อความรีวิวเดิมของตนเอง
* ตรวจสอบความถูกต้องและความครบถ้วนของรีวิวก่อนส่ง
* ตรวจสอบไฟล์รูปภาพก่อนจัดเก็บ
* บันทึกรีวิวลงฐานข้อมูล
* คำนวณคะแนนเฉลี่ยของหอพักใหม่หลังส่งหรือแก้ไขรีวิว
* แสดงรีวิวและคะแนนที่อัปเดตในหน้ารายละเอียดหอพัก

### Out of scope

* การรีวิวหอพักโดย Guest ที่ไม่มีสิทธิ์รีวิว
* การแก้ไขหรือลบรีวิวของผู้ใช้อื่น
* การจัดการหรือตรวจสอบรีวิวโดยเจ้าของหอพัก
* การตรวจสอบและอนุมัติเนื้อหารีวิวโดย Admin
* การจองห้องพัก
* การจัดการข้อมูลหอพัก

## Constraints

* CON-AUTH-01 ผู้ใช้ต้องเข้าสู่ระบบก่อนจึงสามารถเขียนหรือแก้ไขรีวิวได้
* CON-REVIEW-01 ผู้ใช้สามารถแก้ไขได้เฉพาะรีวิวที่ตนเองเป็นผู้เขียน
* CON-REVIEW-02 รีวิวต้องมีคะแนนดาว 1 ถึง 5 ดาว และข้อความก่อนจึงสามารถส่งได้
* CON-REVIEW-03 ระบบต้องป้องกันการส่งรีวิวที่ไม่มีคะแนนหรือไม่มีข้อความ
* CON-FILE-01 รูปภาพที่แนบในรีวิวต้องเป็นไฟล์ประเภท JPG, JPEG หรือ PNG ขนาดไม่เกิน 5 MB ต่อรูป และแนบได้ไม่เกิน 1 รูปต่อรีวิว
* CON-DATA-01 คะแนนเฉลี่ยของหอพักต้องคำนวณใหม่หลังจากมีการส่งหรือแก้ไขรีวิวสำเร็จ โดยใช้ค่าเฉลี่ยเลขคณิตจากคะแนนของรีวิวทั้งหมดที่มีอยู่ในระบบ
* CON-REVIEW-04 ระบบต้องแสดงข้อมูลรีวิวตามข้อมูลที่ผู้ใช้บันทึกไว้โดยไม่บิดเบือน

## Requirements

* FR-REV-01 ระบบต้องแสดงแบบฟอร์มสำหรับเขียนรีวิว พร้อมส่วนให้คะแนนดาวและช่องข้อความ
* FR-REV-02 ระบบต้องให้ผู้พักอาศัยสามารถกำหนดคะแนนหอพักตั้งแต่ 1 ถึง 5 ดาวและเขียนข้อความรีวิวได้
* FR-REV-03 ระบบต้องให้ผู้พักอาศัยสามารถแนบรูปภาพสภาพห้องพักจริงประกอบรีวิวได้ โดยรองรับ JPG, JPEG, PNG ขนาดไม่เกิน 5 MB ต่อรูป และแนบได้ไม่เกิน 1 รูปต่อรีวิว
* FR-REV-04 ระบบต้องตรวจสอบความครบถ้วนและความถูกต้องของข้อมูลรีวิวก่อนบันทึก
* FR-REV-05 ระบบต้องตรวจสอบประเภทและขนาดของไฟล์รูปภาพก่อนจัดเก็บ
* FR-REV-06 ระบบต้องบันทึกข้อมูลคะแนน ข้อความ และรูปภาพรีวิวลงในฐานข้อมูล
* FR-REV-07 ระบบต้องคำนวณคะแนนเฉลี่ยของหอพักใหม่หลังจากมีการส่งรีวิวสำเร็จ โดยใช้ค่าเฉลี่ยเลขคณิตจากคะแนนของรีวิวทั้งหมดที่มีอยู่ในระบบ
* FR-REV-08 ระบบต้องแสดงข้อความแจ้งเตือนเมื่อบันทึกรีวิวสำเร็จ และแสดงรีวิวใหม่ในหน้ารายละเอียดหอพักทันที โดยไม่ต้องผ่านการอนุมัติจาก Admin
* FR-REV-09 หากผู้ใช้เคยรีวิวหอพักแล้ว ระบบต้องแสดงคะแนนและข้อความเดิมเมื่อผู้ใช้เลือกแก้ไขรีวิว
* FR-REV-10 ระบบต้องให้ผู้ใช้แก้ไขคะแนน ข้อความ และรูปภาพในรีวิวของตนเองได้ตลอดเวลา จนกว่าจะถูกลบหรือรีวิวไม่อยู่ในระบบ
* FR-REV-11 ระบบต้องคำนวณคะแนนเฉลี่ยของหอพักใหม่หลังจากแก้ไขรีวิวสำเร็จ โดยคำนวณจากคะแนนของรีวิวทั้งหมดที่มีอยู่ในระบบ
* FR-REV-12 หากผู้ใช้ยกเลิกการเขียนหรือแก้ไขรีวิว ระบบต้องไม่บันทึกการเปลี่ยนแปลง
* FR-REV-13 หากผู้ใช้ไม่ระบุคะแนนหรือข้อความ ระบบต้องแจ้งเตือนและไม่อนุญาตให้ส่งรีวิว จนกว่าจะกรอกข้อมูลที่จำเป็นให้ครบก่อนส่ง
* FR-REV-14 หากรูปภาพไม่ตรงตามเงื่อนไข ระบบต้องแจ้งเตือนและไม่ลบรูปภาพเดิม พร้อมให้ผู้ใช้เลือกไฟล์ใหม่ที่ถูกต้อง

## Quality Requirements

* NFR-PERF-03 ระบบต้องประมวลผลการส่งหรือแก้ไขรีวิวและคำนวณคะแนนเฉลี่ยใหม่ให้เสร็จสิ้นภายใน 2 วินาที ภายใต้สภาวะเครือข่ายปกติ
* NFR-USE-04 แบบฟอร์มเขียนและแก้ไขรีวิวต้องใช้งานง่าย ไม่ซับซ้อน และเข้าใจได้ง่าย
* NFR-DATA-04 ข้อมูลข้อความ คะแนน และรูปภาพรีวิวที่แสดงในระบบต้องตรงกับข้อมูลที่ผู้ใช้บันทึกไว้
* NFR-SEC-04 ระบบต้องป้องกันไม่ให้ผู้ใช้แก้ไขรีวิวของผู้ใช้อื่น

## Acceptance Criteria

* [ ] AC-REV-01 (FR-REV-01, FR-REV-02)

  ```
  Given ผู้พักอาศัยเข้าสู่ระบบและมีสิทธิ์รีวิวหอพัก

  When ผู้พักอาศัยเลือกเขียนรีวิวและระบุคะแนนพร้อมข้อความ

  Then ระบบสามารถบันทึกรีวิวและแสดงรีวิวในหน้ารายละเอียดหอพักได้สำเร็จ
  ```

* [ ] AC-REV-02 (FR-REV-10)

  ```
  Given ผู้พักอาศัยเคยเขียนรีวิวหอพักนี้แล้ว

  When ผู้พักอาศัยเลือกแก้ไขรีวิวและเปลี่ยนแปลงเฉพาะคะแนนหรือข้อความ

  Then ระบบบันทึกเฉพาะส่วนที่ผู้ใช้แก้ไข และคงข้อมูลเดิมของส่วนที่ไม่ได้แก้ไข เช่น หากแก้เฉพาะคะแนนและข้อความ รูปภาพเดิมจะยังคงอยู่
  ```

* [ ] AC-REV-03 (FR-REV-07, FR-REV-11)

  ```
  Given มีการส่งหรือแก้ไขรีวิวสำเร็จ

  When ระบบบันทึกข้อมูลรีวิวเรียบร้อยแล้ว

  Then ระบบคำนวณคะแนนเฉลี่ยของหอพักใหม่และแสดงคะแนนเฉลี่ยที่ถูกต้อง
  ```

* [ ] AC-REV-04 (FR-REV-03, FR-REV-05)

  ```
  Given ผู้พักอาศัยต้องการแนบรูปภาพประกอบรีวิว

  When ผู้พักอาศัยเลือกไฟล์รูปภาพที่ตรงตามเงื่อนไขของระบบ

  Then ระบบสามารถรับและแสดงรูปภาพประกอบรีวิวได้อย่างถูกต้อง
  ```

* [ ] AC-REV-05 (FR-REV-13)

  ```
  Given ผู้พักอาศัยไม่ได้ระบุคะแนนหรือข้อความรีวิว

  When ผู้พักอาศัยกดยืนยันการส่งรีวิว

  Then ระบบแจ้งเตือนให้ผู้ใช้กรอกข้อมูลที่จำเป็นให้ครบก่อนส่ง และไม่บันทึกรีวิวและรูปภาพ
  ```

* [ ] AC-REV-06 (FR-REV-14)

  ```
  Given ผู้พักอาศัยแนบรูปภาพที่มีขนาดเกินกำหนดหรือไม่ใช่ประเภทไฟล์ที่รองรับ

  When ระบบตรวจสอบไฟล์รูปภาพ

  Then ระบบไม่ลบรูปภาพเดิม และแสดงข้อความแจ้งเตือนให้ผู้พักอาศัยเลือกไฟล์ใหม่ที่ถูกต้อง
  ```

* [ ] AC-REV-07 (FR-REV-12)

  ```
  Given ผู้พักอาศัยกำลังเขียนหรือแก้ไขรีวิว

  When ผู้พักอาศัยกดปุ่ม "ยกเลิก"

  Then ระบบไม่บันทึกการเปลี่ยนแปลงและกลับไปยังหน้ารายละเอียดหอพัก
  ```

* [ ] AC-REV-08 (NFR-PERF-03)

  ```
  Given ผู้พักอาศัยส่งหรือแก้ไขรีวิว

  When ระบบประมวลผลรีวิวและคำนวณคะแนนเฉลี่ย

  Then ระบบต้องดำเนินการเสร็จสิ้นภายใน 2 วินาทีภายใต้สภาวะเครือข่ายปกติ
  ```

## Assumptions & Open Questions

* ASM-16 ผู้ใช้ที่สามารถเขียนรีวิวต้องเป็นผู้พักอาศัยที่มีสิทธิ์รีวิวหอพักดังกล่าว
* ASM-17 ผู้ใช้หนึ่งคนสามารถแก้ไขรีวิวของตนเองได้ตลอดเวลา จนกว่าจะถูกลบหรือรีวิวไม่อยู่ในระบบ แต่ไม่สามารถแก้ไขรีวิวของผู้ใช้อื่น
* ASM-18 ระบบมีการกำหนดคะแนนรีวิวเป็นระบบดาว 1 ถึง 5 ดาว
* ASM-19 ระบบมีการกำหนดประเภทและขนาดไฟล์รูปภาพที่สามารถแนบในรีวิวได้ โดยรองรับ JPG, JPEG, PNG ขนาดไม่เกิน 5 MB ต่อรูป และแนบได้ไม่เกิน 1 รูปต่อรีวิว
* ASM-20 คะแนนเฉลี่ยของหอพักคำนวณด้วยค่าเฉลี่ยเลขคณิตจากคะแนนของรีวิวทั้งหมดที่มีอยู่ในระบบ และคำนวณใหม่เมื่อมีการส่งหรือแก้ไขรีวิว
* ASM-21 การตรวจสอบสิทธิ์ของผู้รีวิวเป็นหน้าที่ของระบบก่อนอนุญาตให้ส่งหรือแก้ไขรีวิว
* ASM-22 หลังส่งรีวิวสำเร็จ ระบบจะแสดงรีวิวทันที โดยไม่ต้องผ่านการอนุมัติจาก Admin
* ASM-23 เมื่อผู้ใช้แก้ไขเฉพาะบางส่วนของรีวิว ระบบจะบันทึกเฉพาะส่วนที่แก้ไข และคงข้อมูลเดิมของส่วนที่ไม่ได้แก้ไขไว้
* OQ-01 ไม่มี Open Question ที่ต้องถามเพิ่มเติมในด้านนี้หลังคำตอบที่ได้รับแล้ว

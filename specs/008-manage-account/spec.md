# Feature: จัดการบัญชีผู้ใช้ (Manage User Account)

Spec ID: SPEC-ACC-001
Source: UC-08 จัดการบัญชีผู้ใช้
Use case: UC-08
Owner: ทีมพัฒนาระบบหอพัก
Status: Draft v1
Updated: 2569-09-20

## Goal

ให้ Resident สามารถดูและแก้ไขข้อมูลบัญชีของตนเอง รวมถึงเปลี่ยนรหัสผ่าน
ได้อย่างถูกต้อง ปลอดภัย และสะดวก โดยข้อมูลที่แก้ไขต้องถูกตรวจสอบก่อนบันทึกลงระบบ

## Scope

### In scope

- แสดงข้อมูลบัญชีปัจจุบันของ Resident
- แก้ไขข้อมูลส่วนตัว เช่น ชื่อและเบอร์โทรศัพท์
- เปลี่ยนรหัสผ่านโดยยืนยันรหัสผ่านเดิม
- ตรวจสอบความถูกต้องของข้อมูลก่อนบันทึก
- บันทึกข้อมูลบัญชีที่แก้ไขลงฐานข้อมูล
- แจ้งผลเมื่อบันทึกข้อมูลสำเร็จ
- ยกเลิกการแก้ไขและคืนค่าข้อมูลเดิม

### Out of scope

- การสมัครสมาชิกบัญชีใหม่ (UC-02)
- การเข้าสู่ระบบ (UC-07)
- การจัดการบัญชีของผู้ใช้งานคนอื่นโดย Admin
- การลบบัญชีผู้ใช้
- การเปลี่ยนสิทธิ์หรือบทบาทของผู้ใช้

## Constraints

- CON-ACC-01 ผู้ใช้ต้องเข้าสู่ระบบก่อนจึงสามารถจัดการบัญชีของตนเองได้
- CON-ACC-02 ผู้ใช้สามารถแก้ไขได้เฉพาะข้อมูลบัญชีของตนเอง
- CON-SEC-01 รหัสผ่านต้องถูกจัดเก็บด้วยวิธีที่ปลอดภัยและไม่จัดเก็บเป็นข้อความธรรมดา
- CON-UI-01 หน้าจัดการบัญชีต้องรองรับการใช้งานบนคอมพิวเตอร์และอุปกรณ์พกพา

## Requirements

- FR-ACC-01 ระบบต้องแสดงข้อมูลบัญชีปัจจุบันของ Resident หลังจากเข้าสู่หน้าจัดการบัญชี
- FR-ACC-02 Resident ต้องสามารถแก้ไขข้อมูลส่วนตัวที่ระบบอนุญาต เช่น ชื่อและเบอร์โทรศัพท์
- FR-ACC-03 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึก
- FR-ACC-04 Resident ต้องสามารถเปลี่ยนรหัสผ่านโดยกรอกรหัสผ่านเดิมและรหัสผ่านใหม่
- FR-ACC-05 ระบบต้องตรวจสอบว่ารหัสผ่านเดิมถูกต้องก่อนเปลี่ยนรหัสผ่าน
- FR-ACC-06 ระบบต้องบันทึกข้อมูลบัญชีที่แก้ไขแล้วลงฐานข้อมูล
- FR-ACC-07 เมื่อบันทึกสำเร็จ ระบบต้องแสดงข้อความแจ้งเตือนและแสดงข้อมูลล่าสุด
- FR-ACC-08 เมื่อผู้ใช้ยกเลิกการแก้ไข ระบบต้องไม่บันทึกข้อมูลที่แก้ไขและกลับไปแสดงข้อมูลเดิม

## Quality Requirements

- NFR-ACC-01 การอัปเดตข้อมูลบัญชีควรตอบสนองภายใน 2 วินาทีภายใต้สภาวะการใช้งานปกติ
- NFR-SEC-01 รหัสผ่านต้องไม่ถูกจัดเก็บเป็นข้อความธรรมดา
- NFR-SEC-02 การเปลี่ยนรหัสผ่านต้องตรวจสอบรหัสผ่านเดิมก่อนดำเนินการ
- NFR-USE-01 หน้าจัดการบัญชีต้องใช้งานง่ายและไม่ซับซ้อน
- NFR-ACC-02 ระบบต้องแสดงข้อมูลบัญชีล่าสุดหลังจากบันทึกสำเร็จ

## Acceptance Criteria

- [ ] AC-ACC-01
      Given Resident เข้าสู่ระบบแล้ว
      When Resident เปิดหน้าจัดการบัญชี
      Then ระบบแสดงข้อมูลบัญชีปัจจุบันของ Resident

- [ ] AC-ACC-02
      Given Resident อยู่ในหน้าจัดการบัญชี
      When Resident แก้ไขข้อมูลส่วนตัวและกดบันทึก
      Then ระบบตรวจสอบข้อมูลและบันทึกข้อมูลใหม่ลงฐานข้อมูล

- [ ] AC-ACC-03
      Given Resident กรอกข้อมูลไม่ครบหรือไม่ถูกต้อง
      When Resident กดบันทึก
      Then ระบบแสดงข้อความแจ้งเตือนและไม่บันทึกข้อมูลที่ไม่ถูกต้อง

- [ ] AC-ACC-04
      Given Resident ต้องการเปลี่ยนรหัสผ่าน
      When Resident กรอกรหัสผ่านเดิมถูกต้องและรหัสผ่านใหม่ครบถ้วน
      Then ระบบเปลี่ยนรหัสผ่านและบันทึกข้อมูลอย่างปลอดภัย

- [ ] AC-ACC-05
      Given Resident กรอกรหัสผ่านเดิมไม่ถูกต้อง
      When Resident ยืนยันการเปลี่ยนรหัสผ่าน
      Then ระบบแจ้งว่ารหัสผ่านเดิมไม่ถูกต้องและไม่เปลี่ยนรหัสผ่าน

- [ ] AC-ACC-06
      Given Resident แก้ไขข้อมูลบัญชี
      When Resident กดยกเลิก
      Then ระบบไม่บันทึกการเปลี่ยนแปลงและแสดงข้อมูลเดิม

- [ ] AC-ACC-07
      Given Resident บันทึกข้อมูลบัญชีสำเร็จ
      When ระบบดำเนินการเสร็จสิ้น
      Then ระบบแสดงข้อความยืนยันการบันทึกและแสดงข้อมูลล่าสุด

## Assumptions & Open Questions

- ASM-01 Resident สามารถแก้ไขเฉพาะข้อมูลส่วนตัวที่ระบบกำหนดให้แก้ไขได้
- ASM-02 การเปลี่ยนรหัสผ่านต้องใช้รหัสผ่านเดิมเพื่อยืนยันตัวตน
- ASM-03 ระบบจะไม่เก็บรหัสผ่านเป็นข้อความธรรมดา

## Open Questions

- OQ-01 ยังไม่ได้กำหนดว่าข้อมูลส่วนตัวใดบ้างที่ Resident สามารถแก้ไขได้เพิ่มเติมนอกเหนือจากชื่อและเบอร์โทรศัพท์

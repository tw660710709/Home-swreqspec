# Feature: จัดการข้อมูลหอพัก (Dormitory Management)

Spec ID: SPEC-DOR-003 | Source: ข้อกำหนดความต้องการข้อ 12, 18 | Use case: UC-03

Owner: ทีมพัฒนาระบบหอพัก | Status: Draft v2 | Updated: 2569-09-20

## Goal

เจ้าของหอพักสามารถเพิ่ม แก้ไข และอัปเดตข้อมูลหอพักของตนเองได้อย่างถูกต้องและเป็นปัจจุบัน เพื่อให้ข้อมูลที่แสดงต่อผู้เช่ามีความครบถ้วนและตรงกับสภาพจริงของหอพัก

## Scope

### In scope

* แสดงรายการหอพักที่เป็นของเจ้าของหอพักที่เข้าสู่ระบบ
* เพิ่มข้อมูลหอพักใหม่
* แก้ไขข้อมูลหอพักที่มีอยู่
* แก้ไขข้อมูลห้องพักและราคาค่าเช่า
* แก้ไขข้อมูลสิ่งอำนวยความสะดวก
* แก้ไขกฎระเบียบของหอพัก
* แก้ไขช่องทางการติดต่อ
* อัปโหลดและเปลี่ยนรูปภาพหอพักหรือห้องพัก
* ตรวจสอบความครบถ้วนและความถูกต้องของข้อมูลก่อนบันทึก
* บันทึกข้อมูลหอพักลงในฐานข้อมูล
* แสดงข้อมูลล่าสุดหลังจากบันทึกสำเร็จ

### Out of scope

* การค้นหาและดูข้อมูลหอพักของผู้ใช้งานทั่วไป (UC-01)
* การนัดหมายเพื่อดูห้องพัก (UC-06)
* การจองห้องพัก (UC-12)
* การตรวจสอบและอนุมัติข้อมูลหอพักโดย Admin (UC-13)
* การจัดการข้อมูลหอพักของเจ้าของหอพักรายอื่น

## Constraints

* CON-ACC-01 เจ้าของหอพักต้องเข้าสู่ระบบและผ่านการยืนยันตัวตนก่อนจัดการข้อมูลหอพัก
* CON-AUTH-01 เจ้าของหอพักสามารถจัดการได้เฉพาะข้อมูลหอพักที่เป็นของตนเอง
* CON-DATA-01 ระบบต้องตรวจสอบข้อมูลที่จำเป็นก่อนบันทึก โดยข้อมูลที่จำเป็นประกอบด้วย ชื่อหอพัก, ที่อยู่/ทำเล, ประเภทหอพัก, ราคาค่าเช่า และช่องทางติดต่อ
* CON-FILE-01 รูปภาพที่อัปโหลดต้องเป็นไฟล์ประเภท JPG, JPEG หรือ PNG ขนาดไม่เกิน 5 MB ต่อไฟล์ และไม่เกิน 10 รูปต่อหอพัก/ห้องพัก
* CON-BUS-01 ข้อมูลที่แก้ไขจะต้องถูกบันทึกลงในฐานข้อมูลก่อนจึงจะแสดงเป็นข้อมูลล่าสุด
* DOM-RULE-01 ข้อมูลหอพักและรูปภาพที่เจ้าของหอพักบันทึกต้องตรงกับสภาพและเงื่อนไขจริงของหอพัก และเจ้าของหอพักรับผิดชอบข้อมูลที่กรอก ขณะที่ Admin เป็นผู้ตรวจสอบ/อนุมัติ (Req #18)

## Requirements

* FR-DOR-09 ระบบต้องแสดงรายการหอพักที่เป็นของเจ้าของหอพักที่เข้าสู่ระบบ พร้อมปุ่มเพิ่มหอพักใหม่และแก้ไขข้อมูล
* FR-DOR-10 ระบบต้องให้เจ้าของหอพักสามารถเพิ่มข้อมูลหอพักใหม่ได้ โดยต้องกรอกข้อมูลที่จำเป็นให้ครบถ้วนก่อนบันทึก ได้แก่ ชื่อหอพัก, ที่อยู่/ทำเล, ประเภทหอพัก, ราคาค่าเช่า และช่องทางติดต่อ
* FR-DOR-11 ระบบต้องแสดงแบบฟอร์มข้อมูลหอพักเดิมเมื่อเจ้าของหอพักเลือกแก้ไขข้อมูล
* FR-DOR-12 ระบบต้องให้เจ้าของหอพักสามารถแก้ไขชื่อหอพัก ที่อยู่ ประเภท ราคา สิ่งอำนวยความสะดวก กฎระเบียบ รูปภาพ และช่องทางการติดต่อได้ ส่วนรหัสหอพักและข้อมูลที่ระบบสร้างอัตโนมัติแก้ไขไม่ได้ (Req #12)
* FR-DOR-13 ระบบต้องตรวจสอบความครบถ้วนและความถูกต้องของข้อมูลก่อนบันทึก โดยแจ้งเตือนเป็นรายช่องและระบุสาเหตุที่ต้องแก้ไข เช่น “กรุณากรอกชื่อหอพัก” หรือ “ไฟล์ต้องเป็น JPG, JPEG หรือ PNG และไม่เกิน 5 MB”
* FR-DOR-14 ระบบต้องสามารถอัปโหลดและจัดเก็บรูปภาพหอพักหรือห้องพักตามเงื่อนไขของระบบ โดยรองรับไฟล์ JPG, JPEG, PNG ขนาดไม่เกิน 5 MB ต่อไฟล์ และไม่เกิน 10 รูปต่อหอพัก/ห้องพัก
* FR-DOR-15 เมื่อบันทึกข้อมูลสำเร็จ ระบบต้องอัปเดตข้อมูลหอพักในฐานข้อมูลและแสดงข้อมูลล่าสุด
* FR-DOR-16 หากเจ้าของหอพักยกเลิกการแก้ไข ระบบต้องไม่บันทึกการเปลี่ยนแปลง กลับไปยังหน้ารายการหอพัก และใช้ข้อมูลเดิมจากฐานข้อมูล
* FR-DOR-17 หากข้อมูลจำเป็นไม่ครบถ้วน ระบบต้องแจ้งเตือนเป็นรายช่องพร้อมสาเหตุที่ต้องแก้ไขก่อนบันทึก และไม่บันทึกข้อมูล
* FR-DOR-18 หากไฟล์รูปภาพไม่ตรงตามเงื่อนไข ระบบต้องแจ้งเตือนพร้อมสาเหตุที่ชัดเจน เช่น “ไฟล์ต้องเป็น JPG, JPEG หรือ PNG และไม่เกิน 5 MB” และให้เจ้าของหอพักอัปโหลดไฟล์ใหม่

## Quality Requirements

* NFR-USE-02 แบบฟอร์มสำหรับเพิ่มและแก้ไขข้อมูลหอพักต้องใช้งานง่ายและไม่ซับซ้อน
* NFR-DATA-02 ข้อมูลและรูปภาพของหอพักที่จัดเก็บในระบบต้องตรงกับข้อมูลและสภาพจริงของหอพัก (Req #18)
* NFR-SEC-02 ระบบต้องป้องกันไม่ให้เจ้าของหอพักเข้าถึงหรือแก้ไขข้อมูลของเจ้าของหอพักรายอื่น

## Acceptance Criteria

* [ ] AC-DOR-07 (FR-DOR-09, FR-DOR-11)

  ```
  Given เจ้าของหอพักเข้าสู่ระบบเรียบร้อยแล้ว

  When เจ้าของหอพักเลือกเมนูจัดการข้อมูลหอพัก

  Then ระบบแสดงเฉพาะรายการหอพักที่เป็นของเจ้าของหอพัก พร้อมปุ่มเพิ่มหอพักใหม่และแก้ไขข้อมูล
  ```

* [ ] AC-DOR-08 (FR-DOR-10, FR-DOR-12, FR-DOR-15)

  ```
  Given เจ้าของหอพักอยู่ในหน้าแบบฟอร์มจัดการข้อมูลหอพัก

  When เจ้าของหอพักกรอกหรือแก้ไขข้อมูลหอพักและกดยืนยันการบันทึก

  Then ระบบตรวจสอบข้อมูล บันทึกข้อมูลลงฐานข้อมูล และแสดงข้อมูลล่าสุดอย่างถูกต้อง
  ```

* [ ] AC-DOR-09 (FR-DOR-17)

  ```
  Given เจ้าของหอพักกรอกข้อมูลไม่ครบถ้วน

  When เจ้าของหอพักกดยืนยันการบันทึก

  Then ระบบแสดงข้อความแจ้งเตือนเป็นรายช่องพร้อมสาเหตุที่ต้องแก้ไข เช่น “กรุณากรอกชื่อหอพัก” หรือ “กรุณากรอกที่อยู่/ทำเล” โดยไม่บันทึกข้อมูล
  ```

* [ ] AC-DOR-10 (FR-DOR-18)

  ```
  Given เจ้าของหอพักเลือกอัปโหลดรูปภาพที่ไม่ตรงตามเงื่อนไข

  When ระบบตรวจสอบไฟล์รูปภาพ

  Then ระบบแสดงข้อความแจ้งเตือนพร้อมสาเหตุที่ชัดเจน เช่น “ไฟล์ต้องเป็น JPG, JPEG หรือ PNG และไม่เกิน 5 MB” และให้เจ้าของหอพักเลือกไฟล์ใหม่
  ```

* [ ] AC-DOR-11 (FR-DOR-16)

  ```
  Given เจ้าของหอพักกำลังแก้ไขข้อมูลหอพัก

  When เจ้าของหอพักกดปุ่ม "ยกเลิก"

  Then ระบบไม่บันทึกการเปลี่ยนแปลง กลับไปยังหน้ารายการหอพัก และใช้ข้อมูลเดิมจากฐานข้อมูล
  ```

* [ ] AC-DOR-12 (NFR-DATA-02)

  ```
  Given เจ้าของหอพักบันทึกข้อมูลและรูปภาพของหอพัก

  When ผู้ใช้งานทั่วไปเปิดดูข้อมูลหอพัก

  Then ระบบแสดงข้อมูลและรูปภาพที่เจ้าของหอพักบันทึกไว้อย่างถูกต้อง
  ```

## Assumptions & Open Questions

* ASM-06 เจ้าของหอพักมีบัญชีผู้ใช้งานและสามารถเข้าสู่ระบบได้ก่อนใช้งาน UC-03
* ASM-07 เจ้าของหอพักสามารถจัดการได้เฉพาะหอพักที่เชื่อมโยงกับบัญชีของตนเอง
* ASM-08 ระบบมีการกำหนดประเภทไฟล์และขนาดสูงสุดของรูปภาพที่สามารถอัปโหลดได้ โดยรองรับ JPG, JPEG, PNG ขนาดไม่เกิน 5 MB ต่อไฟล์ และไม่เกิน 10 รูปต่อหอพัก/ห้องพัก
* ASM-09 การตรวจสอบและอนุมัติข้อมูลหอพักเป็นหน้าที่ของ Admin และดำเนินการใน UC-13 โดยเจ้าของหอพักรับผิดชอบข้อมูลที่กรอก
* ASM-10 เมื่อเจ้าของหอพักแก้ไขข้อมูล ข้อมูลที่แสดงต่อผู้ใช้งานทั่วไปจะเป็นข้อมูลล่าสุดตามสถานะของระบบ
* ASM-11 หนึ่งบัญชีสามารถมีหลายหอพักได้
* ASM-12 ระบบเก็บเฉพาะข้อมูลล่าสุดที่บันทึกสำเร็จ ไม่เก็บ version เก่า และข้อมูลที่ยังไม่กดบันทึกจะไม่ถูกนำไปแสดงเป็นข้อมูลล่าสุด
* ASM-13 รหัสหอพักและข้อมูลที่ระบบสร้างอัตโนมัติไม่สามารถแก้ไขได้จากฟอร์มจัดการข้อมูลหอพัก

# Feature: ดูข้อมูลค่าใช้จ่ายห้องพัก (Room Expenses)
Spec ID: SPEC-EXP-011 | Source: ข้อมูลค่าใช้จ่ายห้องพักจาก UC-11 | Use case: UC-11  
Owner: ทีมพัฒนาระบบหอพัก | Status: Draft v2 | Updated: 2569-09-20

## Goal
ผู้พักอาศัยสามารถตรวจสอบรายละเอียดค่าใช้จ่ายห้องพัก (ค่าเช่า ค่าน้ำ ค่าไฟ) และยอดรวมที่ต้องชำระของเดือนปัจจุบันและเดือนก่อนหน้าได้อย่างถูกต้อง โปร่งใส และเข้าถึงข้อมูลได้รวดเร็ว (p95 <= 2 วินาที) โดยเข้าถึงได้เฉพาะบิลห้องพักของตนเองเท่านั้น

## Scope

### In scope
- การแสดงรายละเอียดค่าใช้จ่ายของเดือนปัจจุบัน
- การคำนวณและแสดงยอดรวมที่ต้องชำระ
- การเลือกดูข้อมูลค่าใช้จ่ายย้อนหลังตามเดือน
- การกดดูรายละเอียดเพิ่มเติมของค่าใช้จ่ายแต่ละรายการ
- การจำกัดสิทธิ์การเข้าถึงข้อมูลเฉพาะห้องพักของผู้ใช้

### Out of scope
- การชำระเงินค่าห้องพักผ่าน Payment Gateway ในระบบ
- การสร้างหรือแก้ไขบิลค่าใช้จ่ายโดยเจ้าของหอพัก
- การสร้างไฟล์ PDF ใบเสร็จรับเงิน (Receipt)

## Constraints
- CON-SYS-01 ผู้ใช้ต้องเข้าสู่ระบบและมีข้อมูลผูกกับห้องพัก (Resident) จึงจะเข้าถึงหน้านี้ได้ (Precondition)
- CON-UI-01 หน้าจอต้องรองรับการแสดงผลแบบ Responsive ในทุกขนาดหน้าจออุปกรณ์

## Requirements
- FR-EXP-01 ระบบต้องแสดงรายละเอียดค่าใช้จ่ายล่าสุดของห้องพัก (เช่น ค่าเช่า ค่าน้ำ ค่าไฟ ค่าส่วนกลาง) <- UC-11 main flow ขั้น 1-4
- FR-EXP-02 ระบบต้องคำนวณและแสดงยอดรวมที่ต้องชำระได้อย่างถูกต้อง <- UC-11 main flow ขั้น 5
- FR-EXP-03 ระบบต้องมีตัวเลือกให้ผู้ใช้เลือกดูข้อมูลค่าใช้จ่ายของเดือนก่อนหน้าได้ <- UC-11 alternative flow 3a
- FR-EXP-04 ระบบต้องอนุญาตให้ผู้ใช้กดเลือกดูรายละเอียดเพิ่มเติมของค่าใช้จ่ายแต่ละรายการได้ (เช่น เลขมิเตอร์) <- UC-11 alternative flow 4a
- FR-EXP-05 หากไม่พบข้อมูลห้องพักของผู้ใช้ ระบบต้องแสดงข้อความ "ไม่พบข้อมูลห้องพัก" <- UC-11 exception flow 2a
- FR-EXP-06 หากไม่มีข้อมูลค่าใช้จ่ายสำหรับเดือนที่เลือก ระบบต้องแสดงข้อความ "ไม่มีข้อมูลค่าใช้จ่ายสำหรับเดือนดังกล่าว" <- UC-11 exception flow 3a

## Quality Requirements
- NFR-PERF-01 ระบบต้องดึงข้อมูลและแสดงผลค่าใช้จ่ายด้วยเวลาตอบสนอง p95 <= 2 วินาทีในสภาวะเครือข่ายปกติ
- NFR-ACC-01 ข้อมูลค่าใช้จ่ายและการคำนวณยอดรวมต้องดึงจากฐานข้อมูลล่าสุด เพื่อความถูกต้องของยอดเงิน
- NFR-SEC-01 ผู้ใช้ต้องสามารถเข้าถึงได้เฉพาะข้อมูลบิลค่าใช้จ่ายของห้องพักที่ตนมีสิทธิ์เท่านั้น ป้องกันการดูข้ามห้องอย่างเด็ดขาด

## Acceptance Criteria
- [ ] AC-EXP-01 (FR-EXP-01, FR-EXP-02, NFR-ACC-01)
      Given ผู้ใช้เข้าสู่เมนูค่าใช้จ่ายห้องพัก
      When  มีข้อมูลบิลของเดือนปัจจุบัน
      Then  ระบบแสดงรายละเอียดค่าเช่า ค่าน้ำ ค่าไฟ พร้อมยอดรวมที่คำนวณถูกต้องตรงตามฐานข้อมูล
- [ ] AC-EXP-02 (FR-EXP-03, FR-EXP-06)
      Given ผู้ใช้เลือกดูค่าใช้จ่ายของเดือนก่อนหน้าผ่านตัวเลือกเดือน
      When  เดือนนั้นไม่มีข้อมูลบิล
      Then  ระบบแสดงข้อความ "ไม่มีข้อมูลค่าใช้จ่ายสำหรับเดือนดังกล่าว"
- [ ] AC-EXP-03 (FR-EXP-04)
      Given ผู้ใช้ดูหน้ารายละเอียดค่าใช้จ่าย
      When  ผู้ใช้กดที่รายการ "ค่าน้ำ" หรือ "ค่าไฟ"
      Then  ระบบแสดงข้อมูลเพิ่มเติม เช่น เลขมิเตอร์เดือนก่อน, เลขมิเตอร์เดือนปัจจุบัน และอัตราค่าบริการ
- [ ] AC-EXP-04 (NFR-SEC-01)
      Given ผู้ใช้ที่เป็น Resident ของห้อง A พยายามเข้าถึง URL/API ดูบิลของห้อง B
      When  ส่ง Request เข้าไปที่ Backend
      Then  ระบบต้องปฏิเสธการเข้าถึง (403 Forbidden หรือ 404 Not Found)
- [ ] AC-EXP-05 (FR-EXP-05, CON-SYS-01)
      Given ผู้ใช้เข้าระบบแล้วแต่ยังไม่มีการผูกประวัติกับห้องพักใดๆ
      When  ผู้ใช้เข้าเมนูค่าใช้จ่าย
      Then  ระบบแสดงข้อความแจ้งเตือน "ไม่พบข้อมูลห้องพัก"
- [ ] AC-EXP-06 (NFR-PERF-01)
      Given ผู้ใช้เรียกดูข้อมูลค่าใช้จ่าย
      When  ระบบดำเนินการดึงข้อมูล
      Then  เวลาตอบสนองการแสดงผลต้องเสร็จสิ้นภายใน 2 วินาที

## Assumptions & Open Questions
- ASM-01 ยอดรวม (FR-EXP-02) จะถูกคำนวณและบันทึกไว้ล่วงหน้าฝั่ง Backend ตั้งแต่ตอนสร้างบิล เพื่อลดการคำนวณสดและป้องกันยอดไม่ตรง
- ASM-02 ข้อมูลรายละเอียด (FR-EXP-04) อาจจัดเก็บในรูปแบบ JSON ภายใน Item ของบิล เพื่อให้ยืดหยุ่นในการแสดงฟิลด์มิเตอร์
- ASM-03 การเลือกเดือนก่อนหน้า จะแสดงเป็น Dropdown หรือ List ที่ผู้ใช้เข้าถึงง่าย

# รายการงาน: เข้าสู่ระบบ

- Feature: เข้าสู่ระบบ
- Spec ID: `SPEC-LOGIN-001`
- อ้างอิง: [spec.md](./spec.md), [plan.md](./plan.md)

## 1. ลำดับงาน

| ลำดับ | งาน | รองรับ | สถานะ |
|---|---|---|---|
| T-01 | ตรวจสอบ/จัดเตรียมข้อมูลบัญชีที่ใช้ตรวจ username/email, password, account status และ role โดยไม่เก็บ password แบบ plain text | `FR-LOGIN-01`, `FR-LOGIN-02`, `FR-LOGIN-03`, `FR-LOGIN-05`, `CON-ACC-01`, `CON-SEC-01`, `Q-01` | รอ Q-01 |
| T-02 | รับ username/email และ password ตรวจสอบข้อมูลบัญชีและสถานะก่อนอนุญาตให้เข้าสู่ระบบ; เมื่อบัญชีถูกระงับแจ้งสถานะและช่องทางติดต่อผู้ดูแลระบบ | `FR-LOGIN-01`, `FR-LOGIN-02`, `FR-LOGIN-03`, `CON-LOGIN-01`, `CON-LOGIN-02`, `AC-LOGIN-04` | ยังไม่เริ่ม |
| T-03 | สร้าง session เมื่อ Login สำเร็จ และกำหนดสิทธิ์/นำทางไปหน้าแรกตาม role | `FR-LOGIN-04`, `FR-LOGIN-05`, `CON-LOGIN-03`, `AC-LOGIN-01`, `AC-LOGIN-02`, `Q-01`, `Q-02` | รอ Q-01, Q-02 |
| T-04 | แสดงข้อความผิดพลาดทั่วไปโดยไม่ระบุว่าข้อมูลส่วนใดผิด และไม่สร้าง session เมื่อ Login ไม่สำเร็จ | `FR-LOGIN-06`, `NFR-SEC-03`, `AC-LOGIN-03` | ยังไม่เริ่ม |
| T-05 | เพิ่มช่องทางไปยัง flow สมัครสมาชิกและลืมรหัสผ่าน โดยไม่สร้างรายละเอียดของ flow เหล่านั้น | `FR-LOGIN-07`, `FR-LOGIN-08`, `AC-LOGIN-05`, `AC-LOGIN-06` | ยังไม่เริ่ม |
| T-06 | ตรวจสอบ session ก่อนให้เข้าถึงฟังก์ชันที่กำหนดให้ต้อง Login และนำผู้ไม่มี session ไปหน้า Login | `FR-LOGIN-09`, `AC-LOGIN-07`, `Q-02` | รอ Q-02 |
| T-07 | ทำหน้า Login ให้มีองค์ประกอบตามข้อกำหนดและรองรับอุปกรณ์ที่ระบบรองรับ | `NFR-USE-01`, `CON-UI-01`, `AC-LOGIN-01`, `AC-LOGIN-03`, `Q-03` | รอ Q-03 |
| T-08 | ตรวจการจัดเก็บ password และการรับส่ง Login ผ่าน HTTPS/TLS 1.2 ขึ้นไป ตามหลักฐานตรวจรับที่ทีมกำหนด | `CON-SEC-01`, `CON-SEC-02`, `NFR-SEC-01`, `NFR-SEC-02`, `Q-05` | รอ Q-05 |
| T-09 | วัดเวลาตอบสนอง Login และทดสอบ Acceptance Criteria ตามเงื่อนไขวัดที่ทีมยืนยัน | `NFR-PERF-01`, `AC-LOGIN-01` ถึง `AC-LOGIN-08`, `Q-04` | รอ Q-04 |
